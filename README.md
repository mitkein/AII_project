# AII_project
Данный проект предназначен для автоматической оценки качества алюминиевых отливок (имитированных деталями из аналогичного сплава) на основе анализа изображений
Система предназначена для выявления дефектов отливок на ранних стадиях производства, что позволяет снизить брак и повысить эффективность производственного процесса.

Система использует ансамбль из трех сверточных нейронных сетей и методов машинного обучения для:

•  Классификации деталей как годных или дефектных. (2-классовая классификация)
•  Определения типа дефекта. (5-классовая классификация: потертость, трещина, пора, царапина, годная деталь)
•  Автоматической фиксации параметров съемки. (время, номер детали, результат)
•  Сбора статистики по обработанным деталям. (количество деталей, процент годных/бракованных, таблица с типами дефектов)

Результаты анализа отображаются через локальный веб-интерфейс, предоставляя информацию о качестве деталей, типах дефектов и статистику по обработанным деталям.

▌Ключевые особенности

•  Ансамбль моделей: Использование нескольких моделей для повышения точности и надежности классификации.
•  Собственные сверточные сети: Разработаны две собственные сверточные сети для двух- и пятикллассовой классификации.
•  Transfer Learning: Использование предобученной модели VGG19 для ускорения обучения и повышения точности двухклассовой классификации.
•  Автоэнкодер: Включение автоэнкодеров для выявления аномалий на основе векторных представлений.
•  Обработка изображений: Аугментация данных для повышения устойчивости моделей к вариациям в освещении, ракурсе и размере деталей.
•  Веб-интерфейс: Удобный веб-интерфейс для визуализации результатов и управления системой.
•  Интеграция с камерой Basler: Прямая интеграция с камерой Basler для захвата изображений в реальном времени.
•  Автоматическая фиксация параметров съемки: Отслеживание и сохранение параметров съемки для анализа их влияния на результаты.
•  Сбор статистики: Автоматический сбор и анализ статистики по обработанным деталям.

▌Установка

1. Клонируйте репозиторий:
2. bash
    git clone <https://github.com/mitkein/AII_project/>
    cd <имя_директории_проекта>
Запуск

1. Обучите модели (если необходимо):

  •  Запустите скрипты src/Class2.pyibn и src/Class5.pyibn для обучения собственных моделей и дообучения VGG19.
2. Установите зависимости:
pip install -r requirements.txt
